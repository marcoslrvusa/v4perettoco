# Fluxo GT — Tráfego com Ekyte no Centro

**Propósito:** Mostrar como o squad de Gestão de Tráfego usa o Ekyte como centro durante o ciclo de campanhas — da análise ao reporte.

---

## 1. Macro Fluxo

```
ANÁLISE                       AÇÃO                        REPORTE
   │                            │                            │
   ▼                            ▼                            ▼
GT abre task no           GT executa ajustes          Task de reporte
Ekyte: "Analisar          nas plataformas             é concluída
ROAS do cliente X"        (Meta/Google)                 │
   │                            │                        │
   ▼                            ▼                        ▼
Agente @media-buyer:      Agente documenta no         Agente @relatorios-
→ Puxa dados reais         Ekyte:                     trafego:
→ Identifica padrões      → Comentário na task         → Compila dados
→ Gera recomendações       → Atualiza fase             → Gera HTML/PDF
→ [via V4mos API]          → Próxima task se           → Salva no Drive
  "ROAS caiu 30%           necessário                   → Comenta no Ekyte
  nos últimos 7 dias"       ("Criar nova               → Envia por email
   │                         campanha")                  │
   ▼                                                        ▼
Ekyte → create_task_comment                           Ekyte → create_task_comment
                         Flag ROI dispara              + update_task_phase
                         se ROAS < meta                 + create_ticket se anomalia
```

## 2. Passo a Passo com o Agente

### Análise de Desempenho

```
Usuário: "@media-buyer, analisa o ROAS do cliente X
         nos últimos 30 dias. Dados estão na V4mos."

Agente:
1. Ekyte → get_detailed_task(taskId: 1234)
           → lê: "Analisar ROAS cliente X", fase "analise"
2. [V4mos API] → puxa dados reais de Meta Ads
3. [V4mos API] → puxa dados reais de Google Ads
4. Ekyte → list_tasks(projeto: "cliente X", status: aberto)
           → tasks em andamento do cliente
5. Analisa:
   - ROAS por campanha
   - Gasto por plataforma
   - Breakdown por criativo/audiência
   - Anomalias detectadas
6. Ekyte → create_task_comment(
     taskId: 1234,
     text: "Análise concluída. ROAS geral: 2.3 (meta: 3.0).
            Anomalia detectada: Campanha 'Display' com ROAS 0.8
            nos últimos 7 dias. Recomendações no relatório."
   )
7. Drive → create_file(
     name: "analise-roas-cliente-x-2026-06.md",
     content: relatório completo
   )
8. Ekyte → update_task_phase(taskId: 1234, phase: "recomendacao")
9. Se ROAS < meta: chama @flag-roi para diagnóstico
```

### Otimização de Campanha

```
Usuário: "@midia-paga, preciso criar uma nova campanha
         de prospecção para o cliente X no Meta."

Agente:
1. Ekyte → get_detailed_task(taskId: 1235)
           → lê: "Criar campanha prospecção cliente X"
2. Ekyte → list_tasks(projeto: "cliente X", tipo: "campanha")
           → histórico de campanhas anteriores
3. [V4mos API] → puxa dados de audiência do cliente X:
   - Públicos que mais converteram
   - Horários de melhor performance
   - Creatives com melhor CTR
4. Ekyte → get_detailed_project(projeto: "cliente X")
           → orçamento disponível, período
5. Gera:
   - Estrutura da campanha (CBO, ad sets, ads)
   - Sugestão de segmentação
   - Previsão de ROAS
6. Ekyte → create_task_comment(
     taskId: 1235,
     text: "Estrutura pronta. Orçamento sugerido: R$5k/mês.
            Previsão ROAS: 3.5x. Criativos sendo gerados."
   )
7. Ekyte → create_recurring_task(
     title: "Relatório semanal - cliente X",
     frequency: "weekly",
     responsibleUserId: "..."
   )
8. Ekyte → update_task_phase(taskId: 1235, phase: "execucao")
```

### Relatório (puxado por n8n ou sob demanda)

```
Usuário: "@relatorios-trafego, gera o relatório semanal
         do cliente X."

Agente:
1. Ekyte → list_tasks(
     projeto: "cliente X",
     tipo: "campanha",
     status: "concluida",
     period: "last_7_days"
   )
2. Ekyte → list_task_comments(taskId: ...)
           → coleta resultados reportados
3. [V4mos API] → puxa dados consolidados da semana
4. Gera relatório HTML + análise IA
5. Detecta anomalias:
   - Queda abrupta de ROAS
   - Gasto acelerado (pace)
   - CPA subindo
6. Se anomalia:
   → Ekyte → create_ticket(
       subject: "Anomalia detectada - cliente X",
       priority: "alta"
     )
7. Drive → create_file(
     name: "relatorio-semanal-cliente-x-2026-06-W25.html",
     content: relatório
   )
8. Ekyte → create_task_comment(
     taskId: taskDeRelatorio,
     text: "Relatório semanal gerado. Link: [Drive].
            Anomalias: 1 ticket criado."
   )
9. Envia email com relatório anexado
```

## 3. Agentes Envolvidos

| Agente | Papel | Modelo |
|---|---|---|
| **@media-buyer** | Análise preditiva, arquitetura de contas, otimização ROAS/CPA | `deepseek-v4-flash-free` |
| **@midia-paga** | Estratégia de canais, segmentação, planejamento de campanhas | `gemini-2.5-flash-free` |
| **@relatorios-trafego** | Relatórios consolidados, detecção de anomalias, pace de verba | `gpt-4o-mini` |
| **@cro-otimizacao** | Otimização de conversão pós-clique (LP, formulário) | `gpt-4o-mini` |
| **@flag-roi** | Diagnóstico automático quando ROAS < meta | `deepseek-v4-flash-free` |

## 4. Tabela de Tools Ekyte Usadas pelo GT

| Momento | Tool Ekyte | Para Quê |
|---|---|---|
| Análise | `get_detailed_task` | Ler escopo da análise |
| Análise | `list_tasks` | Histórico de campanhas |
| Análise | `get_detailed_project` | Orçamento e período |
| Recomendação | `create_task_comment` | Resultado da análise |
| Recomendação | `update_task_phase` | Avançar workflow |
| Execução | `create_recurring_task` | Relatório semanal automático |
| Reporte | `list_tasks` | Campanhas concluídas |
| Reporte | `list_task_comments` | Resultados reportados |
| Flag | `create_ticket` | Anomalia detectada |
| Flag | `create_task_comment` | Contexto do ticket |
| Finalização | `update_task` | Marcar concluída |

