# n8n — Motor de Automação Headless

**Propósito:** Workflows automatizados que conectam Ekyte, Google Drive, email e outras ferramentas — opera 24/7 sem intervenção humana.

---

## 1. Arquitetura

```
                    n8n (Docker, VPS)
                    ┌─────────────────┐
                    │   Workflows      │

                    │  └───────────┘   │
                    │  ┌───────────┐   │

                    │  └───────────┘   │
```

## 2. Configuração Docker

```yaml
# docker-compose.yml
services:
  n8n:
    image: n8nio/n8n:latest
    ports:
      - "5678:5678"
    volumes:
      - ./n8n-data:/home/node/.n8n
    environment:
      - N8N_SECURE_COOKIE=false
      - WEBHOOK_URL=https://n8n.v4company.com.br
      - N8N_ENCRYPTION_KEY=${N8N_ENCRYPTION_KEY}
      - EKYTE_API_KEY=${N8N_EKYTE_API_KEY}
      - EKYTE_BASE_URL=https://api.ekyte.com
      - GOOGLE_SERVICE_ACCOUNT_EMAIL=${GOOGLE_SA_EMAIL}
      - GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY=${GOOGLE_SA_KEY}
```

## 3. Catálogo de Workflows

### Periódicos (Cron)

| Workflow | Cron | O Que Faz | Tools Ekyte Usadas |
|---|---|---|---|
| **Briefing do Comitê** | Dom 20h | Puxa tasks/tickets/horas de cada squad, salva JSON consolidado no Drive | `list_tasks`, `list_tickets`, `list_time_trackings`, `list_projects` |
| **Relatório Semanal** | Seg 8h | Compila tasks concluídas da semana, gera PDF, envia por email | `list_tasks` (filtro data), `list_task_comments` |
| **Alerta de OKR** | Seg 9h | Verifica OKRs < 60%, cria ticket automático se necessário | `list_tasks`, `create_ticket` |
| **Ping de Horas** | Sex 18h | Verifica quem não apontou horas na semana, notifica | `list_time_trackings` |

### Orientados a Evento (Webhook)

| Workflow | Gatilho | O Que Faz | Tools Ekyte Usadas |
|---|---|---|---|
| **Flag CSM** | Webhook Ekyte (NPS + CSAT caem) | Cria ticket automático de alerta | `create_ticket`, `get_detailed_task` |
| **Flag Operação** | Webhook Ekyte (sprint atrasada sem FCA) | Cria ticket de bloqueio | `list_tasks`, `create_ticket` |
| **Flag ROI** | Webhook Ekyte (ROAS abaixo da meta) | Classifica tipo, cria CHAS | `list_tasks`, `create_ticket`, `create_task_comment` |
| **Criar Pasta Drive** | Webhook Ekyte (projeto criado) | Cria estrutura de pastas do novo cliente | `list_projects`, `get_detailed_project` |

## 4. Exemplo: Workflow do Comitê (Detalhado)

```json
{
  "name": "Briefing do Comitê - Consolidação Semanal",
  "trigger": "Cron: 0 20 * * 0",
  "steps": [
    {
      "node": "Ekyte - List Tasks",
      "parameters": {
        "workspaceId": "{{ $json.squad.workspaceId }}",
        "status": ["em_andamento", "atrasada"],
        "limit": 200
      }
    },
    {
      "node": "Ekyte - List Tickets",
      "parameters": {
        "workspaceId": "{{ $json.squad.workspaceId }}",
        "status": ["aberto", "em_atendimento"],
        "limit": 200
      }
    },
    {
      "node": "Ekyte - List Time Trackings",
      "parameters": {
        "period": "last_30_days",
        "squadId": "{{ $json.squad.id }}"
      }
    },
    {
      "node": "JS - Consolidar",
      "parameters": {
        "code": "const tasks = $input.all()[0].json;\nconst tickets = $input.all()[1].json;\nconst hours = $input.all()[2].json;\nreturn {\n  squad: $json.squad.name,\n  totalTasks: tasks.length,\n  overdueTasks: tasks.filter(t => t.status === 'atrasada').length,\n  openTickets: tickets.filter(t => t.status === 'aberto').length,\n  totalHours: hours.reduce((a, h) => a + h.hours, 0),\n  generatedAt: new Date().toISOString()\n};"
      }
    },
    {
      "node": "Google Drive - Save JSON",
      "parameters": {
        "folderId": "COMITE_FOLDER_ID",
        "fileName": "dados-{{ $now.format('yyyy-MM-dd') }}.json",
        "content": "{{ $json }}"
      }
    }
  ]
}
```

## 5. Segurança

- n8n nunca recebe tokens de usuário — apenas uma API key de serviço do Ekyte
- Drive acessado via service account (não OAuth de usuário)
- Webhooks do Ekyte com HMAC validation
- Encryption key para credenciais das nodes
