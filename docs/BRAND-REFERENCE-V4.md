## Regras de Uso

1. **Azul é proibido** na identidade V4 — nunca usar azul (#3B82F6 ou similares)
2. **Modo escuro** é padrão: background preto, texto branco
3. **Uppercase + letter-spacing** para labels e chamadas (Barlow Condensed)
4. **Selection color**: vermelho V4 (`#E31919`)
5. **Red gradient** no topbar e elementos principais de destaque
