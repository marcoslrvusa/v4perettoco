# opend

Fetch the latest reply from OpenCode storage via the `opend` CLI.

Use only when the user explicitly asks to view the OpenCode reply/response. Do not run proactively unless requested.

## Usage

```bash
opend
```

Fetches and displays the most recent OpenCode response from storage.
