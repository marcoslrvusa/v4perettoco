Métricas Extraídas

📋 Taxa de Cumprimento
30% do Score
Percentual de combinados que saíram de "Pendente" para "Feito" no período. Meta: > 70%. Abaixo de 40% é alerta vermelho.
Cálculo: combinados_feitos / total_combinados × 100
🎯 Vitalidade das Apostas
25% do Score
Quantas apostas estão ativas, testando teses, vs quantas estão paradas. Meta: 3–5 apostas vivas simultâneas. Menos que 3 = não está testando nada.
Cálculo: (apostas_confirmadas + novas) / total_apostas_no_periodo × 100
📊 Qualidade ROPRE
25% do Score
Média da qualidade dos blocos ROPRE nas últimas calls. Baseado nos diagnósticos dos arquivos de review pós-check-in.
Escala: Forte=3 · Médio=2 · Fraco=1 · Ausente=0
⏱️ Ritmo de Check-ins
20% do Score
Frequência real de check-ins vs a frequência esperada (ideal: 1x por mês). Clientes com ritmo adequado têm score mais alto.
Cálculo: calls_reais_no_periodo / calls_esperadas_no_periodo × 100

Calendário · Geração via Claude
IA gera N semanas de tópicos com mistura de blog posts e email marketing
100%

2
Produção · Blog Posts + Email Marketing
Claude escreve o conteúdo completo, estrutura em JSON e salva no Drive
90%

Setup

Checklist de Configuração

Tudo que precisa para colocar a Engine Room em operação. ~2h de setup para um engenheiro familiarizado com as APIs.

Credenciais (.env)

Preencher v4-automations/config/.env com:

Google: GOOGLE_ADS_DEVELOPER_TOKEN, GOOGLE_ADS_CLIENT_ID/SECRET/REFRESH_TOKEN
Meta: META_APP_ID, META_APP_SECRET, META_ACCESS_TOKEN
Bing: BING_ADS_DEVELOPER_TOKEN, BING_ADS_CLIENT_ID/SECRET/REFRESH_TOKEN
Geral: ANTHROPIC_API_KEY, GMAIL_SENDER

Passo 2

OAuth Google

console.cloud.google.com → Projeto "v4-automations"

APIs a ativar:
Google Ads API · Google Analytics Data API
Gmail API · Google Drive API

Setup:
python3 setup/auth_google.py (1x — gera token.json)

google_ads_customer_id · meta_ad_account_id

Recursos que PRECISAM de setup externo
Bing Ads SDK — pip install bingads + Developer Token em ads.microsoft.com
Google Ads Developer Token — Solicitar em ads.google.com → Centro de API (aprovação automática para test account)
Meta Ads Access Token — Gerar em developers.facebook.com → Marketing API → User Token (long-lived, 60 dias)
Google Drive OAuth — Gerar credentials.json em console.cloud.google.com
Recursos que JÁ FUNCIONAM
