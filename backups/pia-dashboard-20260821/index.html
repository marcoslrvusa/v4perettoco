Guia 01 · Skills

Ativar skills na conversa

Skill é um pacote de instruções especializadas. O agente carrega a skill certa quando você descreve a tarefa — ou force pelo nome.

  1. Descreva a tarefa de forma natural: cliente, objetivo, formato da entrega.
  2. Pra forçar, cite o nome: use a skill copy-producao.
  3. Skills pessoais (ML, Supabase, testes) ficam em privado/ — rode /developer pra acessá-las.
use a skill copy-producao
Guia 02 · Agentes

Delegar pra um agente

Agentes são especialistas com ferramentas próprias (web, dados, design). Você delega e ele devolve a entrega pronta.

  1. Escolha o agente certo: copy-writer, seo-visibilidade, sdr-tech, general…
  2. Peça com contexto completo: papel, cliente, formato de saída e onde salvar.
  3. Revise a entrega antes de enviar pro cliente — erro de agente é seu.
agente copy-writer: reescreva o anúncio…
Guia 03 · Fluxo manual

Rodada completa no terminal

No controle total, rode o fluxo você mesmo — do contexto à entrega — sem passar pelo orquestrador.

  1. Abra o terminal no workspace e rode opencode.
  2. Carregue o contexto: /contexto nome-do-cliente.
  3. Peça a skill/agente pra executar e revise a saída.
  4. Feche com /session-save — a sessão fica em log/.

Guia 04 · Manutenção

Setup & evolução do hub

Se algo quebrar, quiser atualizar ou transformar um fluxo bom em skill compartilhada, esses são os comandos.

  1. Git/gh quebrou → /onboarding valida e conserta tudo de novo.
  2. Skills novas do time → /sync-hub.
  3. Fluxo bom virar skill → /criador-de-skills (duplo-write nas duas pastas).
  4. Publicar pro time → /compartilhar-skill abre o PR.
