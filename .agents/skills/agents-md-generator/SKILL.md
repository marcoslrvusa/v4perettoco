# Agents.md Generator

Generate hierarchical AGENTS.md structures for codebases.

## When to Use

- Creating AGENTS.md files from scratch
- Analyzing codebase for AI agent documentation
- Setting up AI-friendly project documentation
- Generating context files for AI coding assistants

## Structure

Generate hierarchical AGENTS.md with:
1. Project overview and purpose
2. Architecture diagram (text-based)
3. Agent/skill registry with paths
4. Key patterns and conventions
5. Setup and usage instructions

## Patterns

- Start with a tree view of the codebase structure
- Document agent boundaries and responsibilities
- Include decision records for architectural choices
- Link to SKILL.md files for detailed agent instructions
