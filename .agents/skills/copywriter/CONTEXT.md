---

## Posição no fluxo da squad

```
AM (input/OKR) → GT (plano de mídia) → COPY (comunicação/funil) → Design (assets) → GT (ativa)
```

O Copywriter recebe o input do AM (sprint, OKR, FCA) e do GT (plano de mídia, canais, KPIs).
Entrega copy completa para Design produzir os assets e GT ativar.

---

## Como o resultado do Copywriter é medido (KPIs V4)

**Gatilho:** Entregar 90% das tarefas dentro do prazo.

| KR | Métrica | Meta |
|---|---|---|
| KR1 Fidelização | Clientes com LT > 2 com ROI > 1 | > 60% |
| KR2 Satisfação | CSAT posição médio | ≥ 4,0 |
| KR3 Satisfação | Respostas na pesquisa NPS da carteira | ≥ 60% |
| KR4 Eficiência | Timesheet 100% atualizado | sempre |
| KR5 Eficiência | Tarefas entregues dentro do prazo | ≥ 90% |

O Copy é avaliado por **resultado de negócio**, não por criatividade. Uma copy que gera leads é melhor que uma copy premiada que não converte.

## Regras de handoff

**Recebe do AM:**
- OKR do cliente (objetivo + KRs)
- Sprint com as tarefas de copy especificadas
- FCA se houver desvio a ser corrigido

**Recebe do GT:**
- Plano de mídia (canais, objetivos, públicos)
- Performance anterior (o que funcionou/não funcionou)
- Brief de campanha com segmentação e objetivo do conjunto

**Entrega para Design:**
- Copy completa por peça (headline, texto, CTA)
- Notas de direcionamento visual (o que a imagem deve reforçar)
- Variações para teste A/B

**Entrega para GT:**
- Copy aprovada pelo AM
- Hipótese de performance
- Critério para pausar/escalar
