# Quantizing Models with Bitsandbytes

Quantize LLMs using bitsandbytes for memory-efficient inference and training.

## Key Capabilities
- INT8, NF4, FP4 quantization formats
- QLoRA training support
- 8-bit optimizers
- HuggingFace Transformers integration
- 50-75% memory reduction with minimal accuracy loss
