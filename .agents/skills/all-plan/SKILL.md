# all-plan

Collaborative planning using all mounted AI CLIs for comprehensive solution design.

## Usage

Triggers parallel planning across Claude, Codex, Gemini, and OpenCode to generate diverse solution approaches.

## When to Use

- Complex problems needing multiple perspectives
- Architecture decisions with trade-offs
- Design review from multiple angles
- Risk assessment and mitigation planning
