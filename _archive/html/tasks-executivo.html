POP · Agentes no OpenCode Web

Procedimento para ativar agentes na VPS

OpenCode Web já está rodando na VPS. Ambientes e ferramentas configurados. Seguir o POP abaixo para garantir que os agentes estejam disponíveis.

1 Sincronizar repositório na VPS
Puxar a versão mais recente do Builders Hub com as skills e agentes atualizados.
ssh root@vps-hostinger cd /home/opencode/hub git pull origin main # Verificar se há novos agentes em .opencode/agents/ ls .opencode/agents/
2 Configurar modelos no LiteLLM
Garantir que o gateway de modelos tenha as chaves corretas e os rate limits por agente.
# litellm-config.yaml — já existe na VPS # Verificar se as chaves estão no .env: # GEMINI_API_KEY, OPENROUTER_API_KEY # Modelos configurados: deepseek-v4-flash, gemini-2.5-flash, gpt-oss-120b docker restart litellm docker logs litellm --tail 10
3 Conectar MCPs (Ekyte + Google Drive)
Agentes precisam dos MCPs para acessar dados reais. Ekyte é a integração primária.
# Verificar opencode.json na VPS: # "mcp": { # "ekyte": { "type": "remote", "url": "...token...", "enabled": true }, # "google-drive": { "type": "remote", "url": "...", "enabled": true } # } # Testar conectividade: curl -X POST https://api.ekyte.com/mcp/ping \ -H "Authorization: Bearer ${EKYTE_MCP_TOKEN}"
4 Carregar e testar agentes
OpenCode Web descobre agentes automaticamente de .opencode/agents/. Validar com um teste real.
# Listar agentes disponíveis: opencode agents list # Testar agente Account (ciclo completo): opencode run @account-orchestrator "status do squad piloto" # Testar flag de churn: opencode run @flag-churn "analisar cliente X" # Verificar se skills estão sendo carregadas: opencode run @copy-content "quais skills voce tem disponiveis"
5 Liberar acesso aos usuários
Cada squad recebe a URL, a senha e o guia rápido de uso. Nada de setup local.
# URL de acesso: https://opencode.v4.company.com # Senha compartilhada (definida em OPENCODE_SERVER_PASSWORD) # Cada usuário acessa pelo browser — zero instalação # Guia rápido enviado junto com o acesso: # "Use @nome-do-agente + o que voce precisa"
