## Como aplicar no plugin Redirection

Para cada linha da tabela acima:

1. **Ferramentas → Redirection → Redirects → Add New**
2. **Source URL:** cole o caminho da coluna *Origem* (sem barra inicial, sem domínio)
3. **Target URL:** cole o valor da coluna *Destino*
4. Código: **301** (já vem como padrão) · Grupo: padrão · **Não marcar Regex**
5. Salvar — o plugin já testa na hora

**Ordem de prioridade:** a tabela está ordenada por impressões de imagem nos últimos 3 meses. As 20 primeiras concentram 84% do tráfego recuperável — se o tempo for curto, garanta essas.

## Depois de terminar
