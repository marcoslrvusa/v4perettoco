# Metal Indianápolis — Keywords Sementes para SEMrush

Site: preview.indianapolis.com.br (staging) | Setor: Fundição de Ferro Fundido + Usinagem CNC

## Sementes Principais (maior capacidade de expansão)

Estes termos abrem os clusters mais volumosos no Keyword Magic Tool:

| # | Seed | Por que |
|---|---|---|
| 1 | `fundição de ferro` | Core business — expande para tipo de ferro, serviço, regional |
| 2 | `ferro fundido` | Material — expande para cinzento, nodular, preço, peças |
| 3 | `usinagem` | Serviço complementar — expande para CNC, precisão, peças usinadas |
| 4 | `anel de segmento` | Produto nicho com baixa concorrência e alta relevância |
| 5 | `peças fundidas` | Categoria ampla — expande para fornecedor, fabricante, sob medida |
| 6 | `autopeças` | Principal segmento atendido — expande para fabricante, fornecedor |
| 7 | `fundição` + `sob encomenda` | Intenção de contratação direta |
| 8 | `fundição` + `SP` | Geográfico — expande para cidade, região metropolitana |

## Para cruzar no SEMrush

Use **Configuração > Filtro de País**: Brasil
Use **Tipo de Dispositivo**: Desktop (maioria do público industrial)

No Keyword Magic Tool, insira cada seed um por vez e exporte as sugestões. Depois cruze com filtros:
- Volume > 30/mês (público industrial tende a ter buscas menores)
- Intenção comercial + informacional
- Termos com "fornecedor", "fabricante", "preço", "orçamento", "sob encomenda"

---

**Próximo passo recomendado:** extraia o cluster de `anel de segmento` primeiro — é o nicho mais defensável com menos concorrência digital.
